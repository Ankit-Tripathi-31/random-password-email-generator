# Password & Email Generator

A lightweight, responsive browser app with two handy tools:

- **Password generator:** creates an eight-character password containing uppercase and lowercase letters, a number, and a symbol. Password characters are selected with the browser's cryptographic random-number generator.
- **Email idea generator:** takes a name once and suggests eight distinct email-address formats across popular domains, with a copy button for each suggestion.

> Email results are suggestions only. This app does not create mailboxes or check whether an address is available.

## Use the app

Open [`index.html`](./index.html) in a modern browser, then select the tool you want to use. No installation, build step, or account is required.

## Deploy with GitHub Pages

The site is published directly from the `main` branch root using GitHub Pages. After Pages is enabled for the repository, updates pushed to `main` are published automatically. The site is available at:

**https://ankit-tripathi-31.github.io/random-password-email-generator/**
